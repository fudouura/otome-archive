Otome Archive — Fan-made tool preview v13

乙女ゲームの記録を整理する個人向けファンメイドツールです。

できること
- 作品一覧の管理、タイトル・ブランド・キャラ・タグ検索
- プレイ状況、購入状況、機種、開始日・クリア日の記録
- 作品ごとのレビューと項目別評価
- キャラクター・声優・キャラ別感想・お気に入りの記録
- 作品レビューをPNG画像として出力
- JSONバックアップ・復元
- PC／スマートフォンの画面に対応

まず試す
1. ZIPを展開します。
2. otome_archive_pwa フォルダ内の index.html をブラウザで開きます。
3. 作品を登録し、作品詳細から「見開きレビューをPNG出力」を試します。
4. Settings からJSONバックアップを保存できます。

友達と使う（ログイン不要）
- このフォルダ内のファイル一式をHTTPS対応の静的ホスティングに公開し、URLを共有します。
- データは各端末・各ブラウザ内に保存されます。あなたのPCと友達のスマホの記録は別々です。
- 端末をまたいだ同期はありません。ブラウザデータの削除・端末故障に備え、JSONを定期的に保存してください。
- このZIPをダウンロードしただけでは公開URLは作成されません。公開作業が別途必要です。

GitHub Pagesで公開する場合（概要）
1. GitHubにサインインし、新しいリポジトリを作ります。
2. ZIPを展開し、otome_archive_pwa フォルダの中身（index.html、manifest.json、service-worker.js、iconsフォルダ）をリポジトリの最上位にアップロードします。
3. リポジトリの Settings > Pages を開き、公開元を main ブランチ／ルートに設定して保存します。
4. 表示されたURLを開き、PCとスマホで表示・保存を確認してから友達に共有します。
※GitHubの画面や設定項目は変更されることがあります。公開URLができるまでは共有できません。

PWA（ホーム画面への追加）
- HTTPSで公開したURLをスマホで開きます。
- iPhone/iPad：Safariの共有メニューから「ホーム画面に追加」。
- Android：ブラウザメニューから「アプリをインストール」または「ホーム画面に追加」（表示はブラウザにより異なります）。

データとプライバシー
- アカウントやログインはありません。データは利用中のブラウザのlocalStorageに保存されます。
- 同じURLを開いても、別端末・別ブラウザでは別の記録になります。
- 共有端末では記録を他人に見られる可能性があります。
- JSONバックアップには入力した感想などが含まれます。共有先や保管場所に注意してください。

非公式ツールについて
Otome Archiveは個人制作の非公式ファンメイドツールです。各作品・ブランド・キャラクター等の権利はそれぞれの権利者に帰属し、公式運営元とは関係ありません。
